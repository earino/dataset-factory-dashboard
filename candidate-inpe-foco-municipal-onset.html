The question

what a model is asked to predict

A Brazilian municipality has recorded zero active-fire detections (INPE reference-satellite series) for 14 consecutive days through day D. At 13:00 UTC on day D+1 - after INPE's morning consolidation of day-D detections (daily CSV for day D observed published 09:05 BRT on D+1) - given only the municipality's detection history through day D, the calendar, state and biome, will at least one active-fire detection be recorded in that municipality within the next 7 days (event days D+1..D+7)? A useful prediction lets PREVFOGO/IBAMA, state civil defence and municipal fire brigades pre-position crews in a country where detection precedes enforcement, and persistence cannot win by construction.

What you predict

target definition

Binary. Positive: >=1 reference-satellite detection with event timestamp in [D+1 00:00, D+8 00:00) located in municipality m; negative: zero such detections. Label source: the same detection rows (data_pas timestamp + municipio/estado name) that feed the feature history - construction derives the label from event-time windows and must not ship any row with event time > D in feature columns (the label column is a derived aggregate, never a carried source column). Population: all Brazilian municipalities (5570 IBGE codes; ref-era files key by name - construction maps names to IBGE codes and asserts the mapping is total over the detection rows). Conditioning: evaluated pairs are municipality-days with zero detections in [D-13, D] (onset-conditioned; raw-pair variant recorded for comparison).

When the prediction is made

the information cut-off

Instant: 13:00 UTC on day D+1. Features are everything published by then with event time <= D: the complete detection archive through day D (daily file for D observed complete at 09:05 BRT on D+1; detections stream near-real-time at 10-minute granularity during day D), calendar, state/biome. Optional covariates also available at the instant: observed fire-risk grid for day D (NetCDF published ~03:32 server time on D+1) and INPE's forecast risk grids for D+1..D+3 (published on day D). Excluded as post-instant: every detection row with event time > D, and any current-year statistic that only becomes final later. As-of policy: each detection row carries its event timestamp (data_pas / data_hora_gmt); the archive is treated as an append-mostly observation log; LIMITATION (recorded): INPE regenerates archive files (2003-2017 files regenerated 2025-09-08; 2024 file regenerated 2025-06-06) and no historical file vintages are kept, so features are taken from the current archive under the policy that detection rows are immutable observations; construction pins file checksums and must re-fetch one fixed month after >=2 weeks to measure late-row churn before quoting any number.
