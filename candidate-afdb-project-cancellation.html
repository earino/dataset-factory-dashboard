The question

what a model is asked to predict

At the board-approval instant of an African Development Bank Group (AfDB) operation, using only the at-approval attributes AfDB publishes in its IATI activity files (country, sector, financing instrument, commitment, planned span, era), will the operation ultimately be CANCELLED (activity-status 5) rather than COMPLETED (activity-status 3)?

What you predict

target definition

Binary: terminal activity-status = Cancelled (IATI code 5) vs Completed (code 3) for operations whose outcome window has closed. Label source column: activity-status in AfDB's IATI XML (excludable by construction - it ships only as the label). Statuses 1 (Approved, 383) and 2 (Ongoing, 987) are right-censored and never scored; eligibility must be defined from information available at the instant (approval date + planned end + censoring margin), never from eventual status.

When the prediction is made

the information cut-off

The instant the operation enters AfDB's published record at approval: activity-date type 1 (planned start), observed within ~1 day of MapAfrica's displayed 'Approval Date' (P-KE-KF0-013: UI 23 Sept 2026 vs API planned_start 2026-09-24; a bounded construction sample must pin this offset). All features are at-approval attributes; the terminal status is observed only years later at the current coverage end (registry files re-published in full, so the current vintage is the observation frame - a current-vintage retrospective task, not an operational historical claim).
