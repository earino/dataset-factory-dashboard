packaged · GB · 2026-11-04 16:50 UTC

The question

what a model is asked to predict

For a care home location active on the CQC register at monthly vintage T (the 'HSCA Active Locations' file produced on that date), will the location's registration end within the following 12 months (Location Status Inactive-Dereg with a Location HSCA End Date inside (T, T+365d])?

What you predict

target definition

Binary: Location HSCA End Date in (T, T+365d]. Label source: CQC Deactivated Locations file (cumulative; Location HSCA End Date + Location Status; among care homes all-time: 17,046 Inactive-Dereg vs 131 Removed). Label-source columns never ship as features. Censoring: instants whose 12-month window extends past the deactivated file's coverage (2026-11-02 edition) are excluded. FRAMING: the target is the register event (deregistration of the location), which CQC notes can include services continuing under a new registration; not necessarily service cessation - see verdict.uncertainty.

When the prediction is made

the information cut-off

The production instant of a monthly CQC 'HSCA Active Locations' vintage (Europe/London; the date in the file name, e.g. '05 January 2024 HSCA Active Locations'; the weekly sibling CSV states 'This data was produced on <date>' - the same stamping convention). Features are the vintage's own columns only: HSCA start date, care home beds, service types (with/without nursing), service user bands, latest overall rating + its publication date (measured as-of: 0/14,765 care-home rows at T=2024-01-05 carry a rating publication date after T), geography, provider attributes incl. Companies House number. Target = the register event dated after T, read from the cumulative Deactivated Locations product. Archive: monthly vintages 2011-2026 (Drive year folders, anonymous).

Source
CQC register bulk files ('HSCA Active Locations' vintages + 'Deactivated Locations' 2026-11-02 edition) under the Open Government Licence v3.0: free to copy, publish, distribute, transmit, adapt and exploit commercially with the required attribution statement. OGL-UK exempts personal data, third-party rights and official symbols from its grant; the shipped columns were chosen with that in mind: no location name, address, postcode, phone, registered manager, provider id/name, Companies House or charity number ships (identity is a per-instant salted pseudonym; the real-id location map is staging-side and never published), and the redistributed fields (care home beds, service type and service user band flags, latest overall rating + publication date, local authority, region, provider sector, HSCA start year, the vintage instant) are derived from the publisher's own register columns with nothing added beyond our derived binary label, the pseudonym, the derived counts/flags and the partition. The derived dataset is labelled as such throughout and is not CQC's official product.
