The question

what a model is asked to predict

For a U.S. public water system subject to UCMR 5, will its first entry-point sample contain PFOA or PFOS at or above the UCMR 5 minimum reporting level?

What you predict

target definition

any_pfoa_pfos = 1 if the selected first sample has AnalyticalResultsSign = '=' and AnalyticalResultValue >= 0.004 µg/L for either PFOA or PFOS; otherwise 0. The 0.004 µg/L threshold is the UCMR 5 minimum reporting level for both analytes, set before sampling; the 2024 MCL happens to be numerically the same but is not used to define the label. Current-sample result fields are used only to form the label and are excluded from inputs.

When the prediction is made

the information cut-off

Immediately before the first UCMR 5 entry-point sample is collected, recorded as CollectionDate; current-sample result fields are excluded. System attributes and prior UCMR 3 results are treated as pre-sample. Self-reported additional-data elements are attached only when the additional-data row matches the exact available system, facility, sample point, and sample event key, or the exact system, facility, and sample point key when no event code exists; unmatched rows remain missing and no system-level or cross-event fallback is used. The additional-data responses are undated self-reports, so their availability at the decision instant is assumed, not verified.
