The question

what a model is asked to predict

At 12 months before an individual NPDES permit's stated expiration date, will the permitting authority have a successor full-term permit in effect on or before that expiration date, or will the permit run past expiration and continue only administratively?

What you predict

target definition

Per permit version v (one row per NPDES_ID), with versions of the same NPDES_ID ordered by EFFECTIVE_DATE and v's next later version denoted v+1: label 1 (late / no on-time reissuance) if no successor version exists with EFFECTIVE_DATE <= v.EXPIRATION_DATE AND EXPIRATION_DATE > v.EXPIRATION_DATE; label 0 (timely) if such a successor full-term version exists. Requiring the successor's own EXPIRATION_DATE to be later than v's prevents same-expiration modifications from counting as reissuance. Permits whose TERMINATION_DATE or RETIREMENT_DATE falls on or before v.EXPIRATION_DATE are excluded as not requiring reissuance (a post-hoc label-definition exclusion, not a feature).

When the prediction is made

the information cut-off

T equals the evaluated permit version EXPIRATION_DATE minus 365 calendar days. Every shipped history feature uses permit rows, inspections, quarterly noncompliance records, enforcement actions or version-history rows dated strictly before T. The undated NPDES_NAICS and NPDES_PERM_FEATURE_COORDS or NPDES_PERM_COMPONENTS members are excluded because no version or effective-date column lets a join be restricted to records dated before T. Permit and facility descriptors such as STATE_CODE, MAJOR_MINOR_STATUS_FLAG, FACILITY_TYPE_CODE, FACILITY_TYPE_INDICATOR, AGENCY_TYPE_CODE, PRETREATMENT_INDICATOR_CODE, TMDL_INTERFACE_FLAG, IMPAIRED_WATERS and the hydrologic code come from ICIS_PERMITS with an ICIS_FACILITIES fallback only when the permit row is blank; those fallbacks are treated as static attributes already fixed at T, which is an assumption rather than a measured availability ledger. The shipped time column carries EXPIRATION_DATE, a fixed one-year offset from T.
