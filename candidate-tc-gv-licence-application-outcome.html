The question

what a model is asked to predict

For a new goods-vehicle operator licence application in Great Britain, at the instant its listing is published in the Traffic Commissioners' weekly 'Applications and Decisions' (AD) gazette (instant T; the 21-day statutory objection window opens at publication), which resolution will the application reach: granted without a public inquiry, called to a public inquiry (ground code S13), refused, or withdrawn / grant not taken up?

What you predict

target definition

The outcome published in later editions of the same traffic area's AD gazette, linked EXACTLY by the application reference number (the OF-number, which is also the operator licence number; measured in both sample eras): Section 2.1/2.3 = granted without public inquiry; 2.2/2.4 = refused; 4.1 = withdrawn; 4.2 = grant not taken up; 5.1 = notice of public inquiry with a statutory ground code (S13 'Consideration of new application under Section 13' identifies application-related inquiries; S26 'disciplinary action under Section 26' belongs to existing holders and is excluded from this population), followed by 5.2 = decision taken at that inquiry. Candidate primary binary label (decided at construction, before any score): 1 = refused (2.2) or withdrawn/not taken up (4.1/4.2); 0 = granted. Label source columns (the outcome sections) are excluded from the feature set by construction.

When the prediction is made

the information cut-off

The publication date printed on page 1 of the AD edition that lists the application (Europe/London; measured example: east-of-England edition AD-5611 published 28/10/2026 with objection deadline 18/11/2026 = publication + 21 days). Features are exactly the fields of the listing as published: licence class (R/SN/SI), applicant name and legal form, director names, registered address, operating-centre address and postcode, vehicle and trailer authorisation counts, traffic area, publication week. Objections, representations and inquiry outcomes all occur strictly after T, so nothing in the feature set can encode the outcome path.
